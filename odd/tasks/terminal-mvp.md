# terminal-mvp

Objective: a lightweight Rust terminal workspace for Claude Code sessions (tabs, splits, agent sidebar, account switch).
Branch: `feat/terminal-mvp` · Delivery: `ask-on-risk` · Test runner: `cargo test --workspace`

## Specs

- S1: Workspace lives in `/home/rafarth1/workspace/my-terminal`: "hagamos aca y todos los archivos que crees que sea aca /home/rafarth1/workspace/my-terminal".
- S2: Project structure and code follow best practices: "no te olvides usar las mejores practicar para una buena estructura de proyecto y codigo". Cargo workspace with layered crates (headless core, UI app), `rustfmt`, `clippy` lints, tests.
- S3: Built in Rust, visually like the reference screenshot: "Tipo tener algo asi con rust" (sidebar of sessions grouped by project with Waiting/Working filters, tab bar, vertical splits, custom window chrome).
- S4: Real terminal: run shell commands and `claude` CLI inside it: "puedo ponte, hacer todos los comandos basicos de una terminal, escribir claude y que se me habra el CLI etc cierto? donde ahi se conecte pues con los tabs, las barras etc".

- S6: Low RAM compared with Warp (measured 614 MB): "yo uso warp y la verdad consume demasiada ram". Target (estimate, to be measured): app < 250 MB with 5 tabs.
- S7: Use gentle-ai workflow: "no te olvides usar gentle ia".
